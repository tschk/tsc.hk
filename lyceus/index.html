Lyceus is a scratch-trained native model family for domain-specific tasks and personal agents. Its design combines text generation, persistent decision state and efficient sequence processing in one coordinated system.

A research project by The Software Company of Hong Kong.

How the parts fit together

System design

The text-only design brings text diffusion and a decision component together inside one agent. Across refinement rounds, decision state carries information forward to guide what to reveal, revisit or continue. A modular native runtime loads shared model blocks on demand, while still executing every layer each round; local personal and domain profiles remain separate from shared weights. The host controls permissions, evaluation and checkpoints.

Areas of research

Memory

Personal and domain state are intended to carry learning beyond a single conversation. Contextual encoding can distinguish changes in word order that a simple byte average loses; reliable learned recall remains unproven.

Adaptation

Opt-in prototypes let a host grant authority to correct or retire a selected local profile entry. Retirement excludes that entry from profile reads; it does not erase shared weights. Learning corrections from context while preserving unrelated knowledge remains an open challenge.

Growth

The design explores model-proposed changes to parameters and capacity, and, at larger sizes, architecture or source changes for independent review. Current growth experiments are host-scheduled.

Profiles

Controlled prototypes reuse local profiles across model sizes with an aligned codec and projections. Host-selected state can be supplied without loading separate weights for each person or task; compatibility is not universal.

Model family

Configurable model sizes support research into both domain-specific work and personal agents, from small local models to larger specialized systems.

Harness

A separate host is intended to manage permissions, tools and evidence, and assess candidate changes before promoting or rolling back checkpoints.

Mechanism checks are not proof of integrated competence. A recent visible-evidence test did not generalize, and coherent language and reliable correction with retention remain unestablished.
