Lyceus.

Lyceus is a family of experimental transformers built from scratch in C++ and LibTorch. The research asks how a model can learn from feedback, adapt to a person or domain, and change its own weights and capacity over time.

A research project by The Software Company of Hong Kong.

How it is intended to work

Design in progress

The model holds representations and weights, with personal and domain state kept distinct from reusable competence. A host harness is intended to collect approved observations, use Darash search and scoped local or remote tools, and verify evidence. The host owns tool permissions; the model remains independently embeddable.

The harness would turn learning signals into candidate updates or growth, run independent retention checks, and promote a checkpoint or restore an earlier one. Retrieval alone does not change the model. Source and transformer changes are intended to be rarer, gated by size and independent tests.

Current status. A host-scripted synthetic test updates a copied model and reloads an accepted checkpoint after restart. Both update variants passed a small local gate; the checks are not independently protected. Search, scoped execution, a Cloudflare backend and protected evaluation are planned integrations.
